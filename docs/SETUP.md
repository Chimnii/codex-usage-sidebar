# 설치와 설정

1. Windows x64에서 Store 원본 앱을 열고 로그인합니다.
2. 프로젝트를 계속 사용할 고정 폴더에 둡니다. 앱을 완전히 닫고 Setup.cmd를 실행합니다.
3. 시작 메뉴의 **ChatGPT with usage**로 실행합니다. 바로가기를 우클릭해 **작업표시줄에 고정**을 한 번 선택하세요. 이후 Setup은 이 복사본을 가리키는 기존 고정 항목을 이름과 관계없이 갱신합니다.

Setup.cmd는 성공·실패 결과를 표시한 뒤 키를 누를 때까지 창을 유지합니다.

처음에는 인터넷 연결이 필요합니다. Node 24.14.0은 해시를 확인해 .local/tools에 설치하며,
라이브러리는 잠금 파일에 맞춰 설치합니다. 시스템 Node나 PATH를 변경하지 않습니다.
검증한 앱 버전에서 추가 상시 용량은 약 2.4GiB입니다. 업데이트 중에는 새 복사본을 위한 임시 여유 공간이 필요합니다.
일반 파일은 Windows robocopy로 복사하고 목록·크기를 확인합니다. 수정한 EXE·ASAR는 별도로 검증하며 수집기는 앱 안의 Codex CLI를 재사용합니다.
이전에 다른 Node나 개발 환경으로 실행했더라도 Setup은 프로젝트 전용 환경을 한 번 준비합니다.
다시 실행하면 같은 버전의 Node와 잠금 파일이 일치하는 라이브러리를 재사용합니다.
라이브러리는 잠금 파일이 바뀌었거나 필요한 파일이 없을 때 다시 설치하며, 기존 연결 설정은 유지합니다.
원본과 복사본을 동시에 사용하지 마세요. 두 앱은 같은 로그인·대화·설정을 사용합니다.
복사본의 표시 이름은 **ChatGPT with usage**이며, 아이콘은 원본의 파일을 그대로 사용합니다.
창 제목에는 대화 이름과 앱 이름을 함께 표시합니다. 이름 변경은 로그인·캐시 경로에 영향을 주지 않습니다.
Windows 테마를 바꾼 뒤 고정 바로가기의 아이콘이 맞지 않으면 `scripts/Install-UsageShortcut.ps1 -UpdateExistingPin`으로 갱신할 수 있습니다.

| 파일 | 역할 |
|---|---|
| Setup.cmd | 최초 설치, 설정 반영, 새 확장 버전 적용, 바로가기 생성 |
| Launch.cmd | 복사본 검사·준비 후 실행. 평소에는 시작 메뉴 바로가기 사용 |
| Update.cmd | Store 원본 업데이트 확인 → 필요 시 업데이트 → 복사본 재패치·실행 |
| Restore.cmd | 설치된 Store 원본에서 복사본 재생성. 대화·설정 보존 |
| Doctor.cmd | 버전·사용량 연결·UI·복구 상태를 읽기 전용으로 진단 |
| Uninstall.cmd | 복사본과 그 바로가기 제거. 원본·계정·대화·프로젝트 소스 보존 |

## 선택 연결

Antigravity CLI(agy)가 기본 위치에 설치되어 있으면 연결합니다. 없어도 설치가 됩니다.
Claude는 새 설치에서 연결하지 않습니다. 아래 명령은 앱을 종료한 뒤 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
# Antigravity 끄기 / 다른 경로 지정
.\scripts\Setup.ps1 -DisableAntigravity
.\scripts\Setup.ps1 -AntigravityPath 'C:\Tools\agy\agy.exe'

# 실험적 Claude 연결 켜기 / 끄기
.\scripts\Setup.ps1 -EnableClaude
.\scripts\Setup.ps1 -DisableClaude
```

Claude는 기존 Claude Code 로그인 파일을 읽습니다. [인증 설명](DATA.md)을 먼저 확인하세요.
기존 설치 갱신 시에는 기존 연결 설정을 보존합니다.
고급 경로는 생성된 .local/settings.json에서 지정할 수 있습니다. 이 파일을 공유하지 마세요.
표시 순서·숨길 항목·언어·제공자별 갱신 주기는 [usage 설정](OPTIONS.md)을 참고하세요.
설정 수정 후 앱을 종료하고 Setup.cmd를 실행하면 반영됩니다.

## 업데이트·복구

- Store 조회는 6시간 간격이며 도움말 메뉴로 즉시 확인할 수 있습니다. 실패하면 1시간 뒤 재시도합니다.
- 실행 시 설치된 원본과 복사본 버전을 별도로 비교합니다. 원본이 이미 갱신되었다면 Store 조회가 실패해도 복사본 재패치를 진행할 수 있습니다.
- 앱 하단 업데이트 버튼은 정상 종료를 기다립니다. 작업을 마치고 앱을 완전히 종료하세요.
- 앱 복사본은 한 벌만 보관합니다. 업데이트 중에는 기존 실행본을 임시로 유지하고, 새 복사본으로 교체를 마친 뒤 이전 파일을 정리합니다.
- 현재 복사본이 손상되거나 사라졌다면 Restore.cmd로 설치된 원본에서 다시 생성합니다. 이전 앱 버전으로 되돌리는 기능은 없습니다. 패치 호환성이 깨졌다면 Store 원본을 사용하세요.
- 기존 설치의 직전 백업·중복 패치 파일은 다음 Setup 또는 업데이트가 성공한 뒤 함께 정리됩니다.
- 새 프로젝트 소스는 같은 폴더에 갱신하고 Setup.cmd를 실행합니다. 프로젝트 자체의 자동 다운로드는 없습니다.
- 문제가 생기면 Doctor.cmd로 상태를 확인하거나 복사본을 닫고 Store 원본으로 돌아갈 수 있습니다. 공유할 진단은 `powershell -NoProfile -File scripts/Doctor.ps1 -Json`으로 만들고, 원본 로그·설정 파일을 그대로 공유하지 마세요.
- Store CLI가 없으면 Microsoft Store를 갱신합니다. 원본을 직접 업데이트한 뒤 Setup.cmd를 실행해도 됩니다.
- 폴더를 옮길 때는 앱을 닫고 이전 위치에서 Uninstall.cmd를 실행한 뒤, **소스만** 새 위치에 내려받아 Setup.cmd를 실행하세요. .local 폴더와 이전 바로가기를 옮기지 마세요. 로그인·대화는 원래 프로필에 보존됩니다.

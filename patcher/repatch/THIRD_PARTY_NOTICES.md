# Third-party code

vendor/acorn contains Acorn 8.15.0's parser, package metadata, MIT license and
published SHA-512 provenance. See vendor/acorn/package/LICENSE.

The engine reads the Layer 1.1.4 loader and @electron/asar 3.4.1 from local
dependencies prepared by Setup.cmd. These dependencies are not app binaries.
Full notices are in the root THIRD_PARTY_NOTICES.md and LICENSES directory.
